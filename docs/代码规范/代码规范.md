# 代码规范

**目标**：确保不同人/不同AI写的代码风格一致

---

## 文件命名

### 页面文件

- **规则**：小写+短横线
- **示例**：
    - ✅ `art.js` / `art-detail.js`
    - ❌ `Art.js` / `artDetail.js`

### 组件文件

- **规则**：小写+短横线
- **目录**：`/components/xxx/xxx.wxml`
- **示例**：
    - ✅ `role-badge` / `gold-button`
    - ❌ `RoleBadge` / `goldButton`

---

## 变量命名

### JS变量

- **规则**：驼峰命名
- **示例**：
    - ✅ `userRole` / `totalLeads` / `isNewbie`
    - ❌ `user_role` / `TotalLeads`

### data字段

- **规则**：驼峰命名，与数据库字段保持一致
- **示例**：

```jsx
data: {
  articles: [],
  currentTab: 'all',
  isLoading: false
}
```

### 云函数名

- **规则**：下划线分隔（遵循云开发习惯）
- **示例**：
    - ✅ `get_articles` / `submit_lead` / `make_secure_call`
    - ❌ `getArticles` / `submitLead`

---

## 函数命名

### 事件处理函数

- **规则**：`on` + 动作
- **示例**：

```jsx
onLoad() {},
onTabChange() {},
onSecureCall() {},
onSubmit() {}
```

### 业务函数

- **规则**：动词开头，驼峰命名
- **示例**：

```jsx
loadArticles() {},
checkPermission() {},
formatPhone() {}
```

---

## 注释规范

### 必须注释的场景

1. **复杂业务逻辑**

```jsx
// 撞单检测：查询相同手机号在其他人名下的次数
const collisionCount = await db.collection('clients')
  .where({ phone: realPhone })
  .count();
```

1. **权限判断**

```jsx
// 访客只能看公开内容
if (role === 'visitor') {
  query = query.where({ securityLevel: '公开' });
}
```

1. **临时方案/待优化**

```jsx
// TODO: 后续改为云端读取LPR
const DEFAULT_LPR = 3.45;
```

### 禁止的注释

- ❌ 废话注释：`// 获取数据` `// 调用函数`
- ❌ 大段注释代码（直接删除）

## 代码格式

### 缩进

- **规则**：2空格（微信开发者工具默认）
- **禁止**：Tab或4空格

### 引号

- **规则**：单引号 `'`
- **示例**：
    - ✅ `const role = 'visitor';`
    - ❌ `const role = "visitor";`

### 分号

- **规则**：语句结尾加分号
- **示例**：
    - ✅ `const a = 1;`
    - ❌ `const a = 1`

## WXML规范

### 属性顺序

```xml
<view
  class="card"
  wx:if="show"
  bindtap="onTap"
  data-id="id">
</view>
```

**顺序**：class → 条件渲染 → 事件 → data属性

### 条件渲染

- **简单判断**：`wx:if`
- **频繁切换**：`hidden`
- **禁止**：`wx:if + wx:else` 嵌套超过2层

## 颜色规范

### 标准配色

- **背景黑**: `#0a0a0a` (页面主背景)
- **次级黑**: `#111` / `#1a1a1a` (卡片背景)
- **标准金色**: `#D4B083` (按钮/标题/高亮)
- **边框灰**: `#222` / `#333` (分割线/边框)
- **文字灰**: `#444` / `#666` / `#888` (次要文字)

### 禁止使用的颜色

❌ `#d4af37` (旧版金色，已废弃)

❌ `#FFD700` (亮金色，不符合黑金风格)

❌ 任何其他金色色号

**说明**：全项目统一使用 `#D4B083` 作为标准金色，与admin页面、组件库保持一致。

## WXSS规范

### 单位

- **规则**：使用 `rpx`（自适应）
- **固定尺寸**：`1rpx` 边框除外可用 `1px`

### 选择器

- **优先**：class选择器
- **禁止**：id选择器、标签选择器（除非全局样式）

### 命名

- **规则**：BEM规范（Block-Element-Modifier）
- **示例**：

```css
.card { }
.card__title { }
.card--gold { }
```

## 云函数规范

### 入口文件结构

```jsx
const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });
const db = cloud.database();

exports.main = async (event, context) => {
  const { param1, param2 } = event;
  const { OPENID } = cloud.getWXContext();
  
  try {
    // 业务逻辑
    return { code: 0, data: {} };
  } catch (err) {
    console.error(err);
    return { code: 500, message: '服务器错误' };
  }
};
```

### 错误处理

- **必须**：try-catch包裹
- **必须**：返回统一格式 `{ code, message, data }`
- **必须**：console.error记录错误
