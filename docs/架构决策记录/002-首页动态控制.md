# 002-首页动态控制

## 状态

✅ 已实施

## 背景

首页是用户进入小程序的第一个页面，需要根据用户角色和业务类型显示不同的界面和功能。为了避免创建多个首页文件，提高代码复用性，需要设计一个动态控制机制，使同一页面能够适应不同角色的需求。

## 决策

### 1. 动态控制架构

采用**单页面多状态**设计，通过条件判断和动态数据绑定实现不同角色的界面切换。

#### 核心原则
- **单一入口**：所有角色通过同一个首页入口进入
- **动态调整**：根据角色和业务类型动态调整界面元素
- **权限控制**：基于角色权限控制功能访问
- **用户体验**：确保每种角色都有最佳的视觉和交互体验

### 2. 实现方式

#### 核心文件
- `miniprogram/pages/index/index.js` - 首页动态控制逻辑
- `miniprogram/pages/index/index.wxml` - 首页模板
- `miniprogram/pages/index/index.wxss` - 首页样式

#### 关键设计

1. **工具列表动态切换**：
   - 定义不同角色的工具列表常量
   - 根据角色和业务类型动态设置 `bSideTools` 数据

2. **TabBar 动态显示/隐藏**：
   - 客户和租客隐藏 TabBar
   - 内部人员显示 TabBar
   - 使用 `wx.showTabBar()` 和 `wx.hideTabBar()` 实现

3. **标题和UI元素动态调整**：
   - 根据角色动态设置榜单标题
   - 根据角色调整界面布局和元素显示

4. **客户视角的内容限制**：
   - 客户角色限制内容访问和跳转
   - 提供授权机制解锁更多内容

### 4. 动态控制逻辑

#### 1. 角色判断和工具分配

```javascript
updateIdentity() {
  const roleCode = RoleManager.getCurrentRole();
  const isBroker = roleCode === 'broker';
  const isAnchor = roleCode === 'anchor';
  const isStudent = roleCode === 'student';
  const isVisitor = roleCode === 'visitor';
  const isCustomer = roleCode === 'customer';
  const isTenant = roleCode === 'tenant';
  
  // 获取用户业务类型
  const profile = app.globalData.userProfile;
  const businessType = profile?.business_type || wx.getStorageSync('businessType');

  let tools = [];
  if (isBroker && businessType === 'rental') {
    tools = BROKER_RENTAL_TOOLS;  // 租赁经纪人：6个工具
  } else if (isBroker) {
    tools = BROKER_TOOLS;  // 二手房/新房经纪人：8个工具
  } else if (isAnchor) {
    tools = ANCHOR_TOOLS;
  } else if (isStudent || isVisitor) {
    tools = STUDENT_TOOLS;
  }

  // 获取用户业务类型
  const isRentalBroker = isBroker && businessType === 'rental';
  
  this.setData({
    userRole: roleCode,
    isVisitor: isVisitor,
    isStudent: isStudent,
    isBroker: isBroker,
    isCustomer: isCustomer,
    isTenant: isTenant,
    isAnchor: isAnchor,
    storeName: app.globalData.storeName || '星火计划 · 天津战区',
    rankTitle: isRentalBroker ? '本月签约榜' : (isBroker ? '今日经纪人带看榜' : '今日大区获客榜'),
    bSideTools: tools,
    isPreviewMode: false,
    isRentalBroker: isRentalBroker
  });

  // 核心逻辑：动态控制 TabBar 显示/隐藏
  if (isCustomer || isTenant) {
    // 如果是客户或租客，把底部导航栏藏起来！
    wx.hideTabBar({ animation: false });
  } else {
    // 如果是内部人员，把底部导航栏显示出来！
    wx.showTabBar({ animation: false });
  }
}
```

#### 2. 租户重定向

```javascript
onShow() {
  // 如果当前角色是租户，重定向到租户首页
  const currentRole = RoleManager.getCurrentRole();
  if (currentRole === 'tenant') {
    wx.redirectTo({
      url: '/pages/tenant/tenant',
      fail: (err) => {
        console.error('重定向到租户首页失败:', err);
      }
    });
    return; // 阻止后续代码执行
  }
  
  this.updateIdentity();
  this.getReports(); // 页面显示时获取战报数据
}
```

### 5. 权限控制和内容限制

#### 1. 客户视角的内容限制

```javascript
// C端文章点击：封堵跳转
onArticleTap(e) {
  // 如果是客户，不能让他跳走，因为一跳走 TabBar 可能会露出来，或者看到不该看的东西
  if (this.data.isCustomer) {
    if (this.data.isUnlocked) {
      wx.showModal({
         title: '查看全文',
         content: '完整版分析报告已包含在资料包中，请联系顾问领取 PDF。',
         showCancel: false,
         confirmText: '联系顾问',
         success: (res) => {
           if(res.confirm) this.onCallAgent();
         }
      });
    } else {
      // 没解锁就弹授权
      this.setData({ showAuthModal: true });
    }
    return;
  }

  // 内部人员随便看
  wx.switchTab({ url: '/pages/art/art' });
}
```

#### 2. 资料宫格点击处理

```javascript
onGridTap(e) {
  const item = e.currentTarget.dataset.item;
  
  if (this.data.isPreviewMode) {
    wx.showToast({ title: '右上角转发给客户', icon: 'none' });
    return;
  }

  if (this.data.isUnlocked || item.type === 'free') {
    wx.showToast({ title: '正在打开 ' + item.name, icon: 'none' });
  } else {
    this.setData({ showAuthModal: true });
  }
}
```

## 影响

### 正面影响

1. **代码复用**：避免创建多个首页文件，减少代码冗余
2. **维护性**：集中管理所有角色的首页逻辑，便于维护
3. **一致性**：确保所有角色的首页风格一致
4. **灵活性**：易于添加新角色和调整现有角色的界面
5. **用户体验**：为每种角色提供定制化的界面和功能

### 风险

1. **复杂度**：单文件逻辑可能变得复杂
2. **性能**：频繁的条件判断可能影响性能
3. **测试**：需要测试所有角色的首页场景
4. **可读性**：复杂的条件判断可能降低代码可读性

## 缓解措施

1. **模块化**：将复杂逻辑拆分为多个方法
2. **注释**：添加详细的代码注释
3. **测试**：为每种角色场景编写测试用例
4. **优化**：使用计算属性和缓存减少重复计算
5. **文档**：详细记录动态控制逻辑和设计决策

### 页面结构

```html
<view class="tools-container" wx:if="{{!isPreviewMode}}">

    <view class="tool-icon">{{item.icon}}</view>

  </view>

<!-- 客户视角资料宫格 -->
<view class="grid-container" wx:if="{{isPreviewMode || isCustomer}}">
  <view class="grid-item" wx:for="{{customerGrid}}" wx:key="{{index}}"
        data-item="{{item}}" bindtap="onGridTap">
    <view class="grid-icon">{{item.icon}}</view>
    <view class="grid-name">{{item.name}}</view>
    <view class="grid-lock" wx:if="{{item.type === 'lock'}}">🔒</view>
  </view>
</view>
```

### 性能优化

1. **数据缓存**：缓存角色信息和工具列表，减少重复计算
2. **条件渲染**：使用 `wx:if` 减少DOM节点
3. **事件委托**：使用事件委托减少事件监听器
4. **异步加载**：非关键数据异步加载
