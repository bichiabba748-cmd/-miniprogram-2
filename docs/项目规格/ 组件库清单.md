# 组件库清单

## 核心组件（优先实装）

### 1. 角色徽章 `role-badge`

**路径**：`/components/role-badge/`

**用途**：显示用户角色标识

**Props**：

```jsx
{
  role: 'visitor | student | anchor | broker | admin',
  size: 'small | medium | large'  // 可选，默认medium
}
```

**样式**：

- visitor：灰色 #666
- student：蓝色 #4a90e2
- anchor：橙色 #f5a623
- broker：绿色 #7ed321
- admin：金色 #d4af37

**使用示例**：

```xml
<role-badge role="userRole" size="small" />
```

---

### 2. 金色按钮 `gold-button`

**路径**：`/components/gold-button/`

**用途**：主要操作按钮（黑金风格）

**Props**：

```jsx
{
  text: String,           // 按钮文字
  type: 'solid | outline', // 实心/空心，默认solid
  disabled: Boolean,      // 是否禁用
  loading: Boolean        // 是否加载中
}
```

**样式**：

- solid：金底黑字 #d4af37 + #0a0a0a
- outline：金边白字
- 圆角：8rpx
- 高度：88rpx

**Events**：

- `bindtap` → 点击事件

**使用示例**：

```xml
<gold-button 
  text="立即加入" 
  type="solid"
  bindtap="onJoin" />
```

---

### 3. 磨砂卡片 `frost-card`

**路径**：`/components/frost-card/`

**用途**：内容容器（黑金磨砂质感）

**Props**：

```jsx
{
  title: String,         // 卡片标题（可选）
  icon: String,          // 标题图标emoji（可选）
  color: String          // 主题色，默认gold
}
```

**样式**：

- 背景：半透明黑 rgba(10,10,10,0.8)
- 圆角：16rpx
- 边框：1rpx 金色流光
- 内边距：32rpx

**Slot**：

- 默认slot：卡片内容

**使用示例**：

```xml
<frost-card title="战绩统计" icon="🏆">
  <view>本月获客：158</view>
</frost-card>
```

---

### 4. 安全等级标签 `security-tag`

**路径**：`/components/security-tag/`

**用途**：文案安全等级标识

**Props**：

```jsx
{
  level: '绝密 | 内部 | 公开'
}
```

**样式**：

- 绝密：红底白字 #ff3b30
- 内部：橙底黑字 #ff9500
- 公开：绿底白字 #34c759
- 圆角：4rpx
- 字号：20rpx

**使用示例**：

```xml
<security-tag level="绝密" />
```

---

### 5. 空状态 `empty-state`

**路径**：`/components/empty-state/`

**用途**：数据为空时的占位提示

**Props**：

```jsx
{
  type: 'no-data | no-permission | network-error',
  text: String,          // 自定义提示文字（可选）
  actionText: String,    // 操作按钮文字（可选）
}
```

**Events**：

- `bindaction` → 点击操作按钮

**样式**：

- 图标：灰色大图标
- 文字：灰色 #999
- 居中显示

**使用示例**：

```xml
<empty-state 
  type="no-permission"
  text="加入星火计划，解锁完整军火库"
  actionText="立即加入"
  bindaction="onJoin" />
```

## 组件开发规范

### 目录结构

```
/components/
  ├─ role-badge/
  │  ├─ role-badge.wxml
  │  ├─ role-badge.wxss
  │  ├─ role-badge.js
  │  └─ role-badge.json
```

### JSON配置

```json
{
  "component": true,
  "usingComponents": {}
}
```

### JS模板

```jsx
Component({
  properties: {
    role: {
      type: String,
      value: 'visitor'
    }
  },
  data: {},
  methods: {}
});
```

---

## 使用规范

### 页面引入组件

```json
{
  "usingComponents": {
    "role-badge": "/components/role-badge/role-badge",
    "gold-button": "/components/gold-button/gold-button"
  }
}
```

### 禁止事项

- ❌ 在页面内直接写重复的UI逻辑
- ❌ 修改组件内部样式（应通过props控制）
- ❌ 组件耦合业务逻辑（应保持纯UI）
