# 问题复盘：勋章墙显示异常

## 问题描述

### 发生时间
2026年2月6日

### 影响范围
- 用户个人中心页面的勋章墙功能
- 所有角色（学员、主播、经纪人）的勋章显示

### 严重程度
P1（重要问题）- 影响用户体验，但不阻塞核心功能

### 问题现象
用户切换不同角色时，勋章墙显示的勋章数量不正确：
- 学员角色只显示1个勋章（应该显示3个）
- 主播和经纪人角色显示的勋章数量也不对
- 所有角色都只显示"初出茅庐"一个通用勋章

## 问题定位

### 初步分析
1. 检查前端代码：`profile.js` 正确调用云函数并传递角色参数
2. 检查云函数代码：`getProfileData/index.js` 中的勋章分类逻辑
3. 添加详细日志：在云函数中添加日志输出，查看角色判断逻辑

### 排查过程

#### 步骤1：检查前端代码
```javascript
// profile.js
wx.cloud.callFunction({
  name: 'getProfileData',
  data: {
    role: currentRole
  },
  success: res => {
    console.log('[getProfileData] 调用成功：', res);
    const { code, data } = res.result;
    
    if (code === 0 && data) {
      console.log('[getProfileData] 返回数据：', {
        role: data.role,
        medalsCount: data.medals ? data.medals.length : 0,
        medals: data.medals
      });
      
      if (data.medals && data.medals.length > 0) {
        console.log('[勋章数据] 角色:', data.role, '勋章数量:', data.medals.length);
        data.medals.forEach((medal, index) => {
          console.log(`[勋章${index}]`, medal.name, medal.icon, 'locked:', medal.locked);
        });
        this.setData({ medals: data.medals });
      }
    }
  }
});
```

**结论**：前端代码正常，正确调用云函数并传递角色参数

#### 步骤2：检查云函数代码
```javascript
// getProfileData/index.js
// 定义勋章分类
const commonMedals = [
  {
    id: 'first_login',
    name: '初出茅庐',
    icon: '🌱',
    condition: '完成首次登录并加入星火计划'
  }
];

const learningMedals = [
  {
    id: 'content_master',
    name: '军火专家',
    icon: '⚔️',
    condition: '累计收藏30篇文案'
  },
  {
    id: 'course_complete',
    name: '学霸达人',
    icon: '📚',
    condition: '完成10门课程学习'
  }
];

const anchorMedals = [
  {
    id: 'lead_hunter',
    name: '获客达人',
    icon: '🎯',
    condition: '累计获客10组'
  },
  {
    id: 'lead_master',
    name: '百人斩',
    icon: '🔥',
    condition: '累计获客100组'
  }
];

const brokerMedals = [
  {
    id: 'first_deal',
    name: '首单达人',
    icon: '🎉',
    condition: '完成首单成交'
  },
  {
    id: 'deal_master',
    name: '成交达人',
    icon: '💼',
    condition: '累计成交10单'
  }
];

// 根据角色组合勋章列表
let roleMedals = [];
roleMedals = [...commonMedals];

// 主播和经纪人有学习勋章
if (role === 'anchor' || role === 'broker') {
  roleMedals = [...roleMedals, ...learningMedals];
}

// 主播专属获客勋章
if (role === 'anchor') {
  roleMedals = [...roleMedals, ...anchorMedals];
}

// 经纪人专属转化勋章
if (role === 'broker') {
  roleMedals = [...roleMedals, ...brokerMedals];
}
```

**结论**：发现问题！`student` 角色没有被包含在任何条件中，所以只有通用勋章（初出茅庐）

### 根本原因
云函数中角色判断逻辑不完整，`student` 角色被遗漏，导致学员角色只能获得通用勋章。

## 解决方案

### 临时方案
无临时方案，必须修复代码逻辑

### 永久方案
修改 `getProfileData/index.js` 中的角色判断逻辑，将 `student` 角色包含在学习勋章的条件中：

```javascript
// 修改前：主播和经纪人有学习勋章
if (role === 'anchor' || role === 'broker') {
  roleMedals = [...roleMedals, ...learningMedals];
}

// 修改后：学员、主播和经纪人有学习勋章
if (role === 'student' || role === 'anchor' || role === 'broker') {
  roleMedals = [...roleMedals, ...learningMedals];
}
```

### 验证结果
- 学员角色：显示3个勋章（初出茅庐 + 军火专家 + 学霸达人）✅
- 主播角色：显示4个勋章（初出茅庐 + 获客达人 + 军火专家 + 百人斩）✅
- 经纪人角色：显示3个勋章（初出茅庐 + 首单达人 + 军火专家）✅
