# 星火计划微信小程序用户手册

## 1. 产品简介

星火计划（Spark Plan）是一款专为房产经纪行业打造的微信小程序 SaaS 平台，融合了内容分发、CRM客户管理和培训三大核心模块，旨在通过新媒体赋能房产经纪业务。

### 核心功能
- **内容分发**：提供海量文案素材、营销工具，助力经纪人高效获客
- **CRM管理**：客户线索管理、跟进记录、业绩统计，提升客户转化率
- **培训体系**：实战课程、技能培训、排行榜激励，助力经纪人专业成长

### 适用人群
- 房产经纪人（租赁、二手房、新房）
- 房产主播
- 房产培训机构
- 房产中介门店

## 2. 注册与登录

### 2.1 首次注册
1. **扫描二维码**：通过邀请码或分享链接进入小程序
2. **授权登录**：点击"授权登录"按钮，允许小程序获取微信信息
3. **完善信息**：填写姓名、手机号等基本信息
4. **选择角色**：根据自身身份选择相应角色（经纪人、主播、学员等）
5. **提交审核**：等待管理员审核通过

### 2.2 日常登录
1. **打开小程序**：在微信中搜索"星火计划"或从历史记录进入
2. **自动登录**：小程序会自动使用微信账号登录
3. **角色切换**：如需切换角色，可在个人中心进行操作

### 2.3 忘记密码
- 小程序使用微信账号登录，无需密码
- 如遇到登录问题，请联系管理员重置账号

## 3. 功能模块使用指南

### 3.1 内容分发模块

#### 3.1.1 星火日签
- **功能说明**：每日生成营销文案和图片，可直接分享到朋友圈
- **操作流程**：
  1. 进入"工具"页面，点击"星火日签"
  2. 选择模板类型（早安、晚安、节日等）
  3. 编辑文案内容（可选）
  4. 点击"生成图片"
  5. 保存图片或直接分享
- **使用技巧**：
  - 定期更新日签内容，保持朋友圈活跃度
  - 结合热点事件，提高文案关注度

#### 3.1.2 文案军火库
- **功能说明**：提供海量房产营销文案，支持分类浏览和搜索
- **操作流程**：
  1. 进入"文案"页面
  2. 选择文案分类（获客、成交、节日等）
  3. 浏览文案列表，点击查看详情
  4. 点击"复制文案"按钮，粘贴到需要的地方
- **使用技巧**：
  - 使用搜索功能快速找到目标文案
  - 收藏常用文案，方便下次使用

#### 3.1.3 直播脚本
- **功能说明**：提供专业的房产直播脚本模板
- **操作流程**：
  1. 进入"工具"页面，点击"直播脚本"
  2. 选择脚本类型（新房、二手房、租赁等）
  3. 查看脚本内容，可进行编辑修改
  4. 复制或导出脚本

### 3.2 CRM客户管理模块

#### 3.2.1 线索管理
- **功能说明**：管理客户线索，跟踪客户状态
- **操作流程**：
  1. 进入"CRM"页面
  2. 查看客户列表，可按状态筛选
  3. 点击客户进入详情页
  4. 记录跟进情况，更新客户状态
- **使用技巧**：
  - 及时更新客户状态，保持数据准确性
  - 定期回访潜在客户，提高转化率

#### 3.2.2 客户录入
- **功能说明**：手动录入新客户信息
- **操作流程**：
  1. 进入"CRM"页面，点击"录入客户"
  2. 填写客户姓名、电话、意向等信息
  3. 选择客户来源（直播间、短视频等）
  4. 点击"提交"完成录入

#### 3.2.3 跟进记录
- **功能说明**：记录与客户的每一次互动
- **操作流程**：
  1. 进入客户详情页
  2. 点击"添加跟进记录"
  3. 选择跟进方式（电话、微信、面访等）
  4. 填写跟进内容和下次跟进时间
  5. 点击"保存"

### 3.3 培训模块

#### 3.3.1 实战课程
- **功能说明**：提供房产经纪相关的专业课程
- **操作流程**：
  1. 进入"课程"页面
  2. 选择课程分类（获客技巧、谈判技巧等）
  3. 点击课程进入详情页
  4. 观看课程视频或阅读课程内容

#### 3.3.2 排行榜
- **功能说明**：展示经纪人业绩排行，激发竞争意识
- **操作流程**：
  1. 进入"排行榜"页面
  2. 查看不同维度的排行榜（获客、成交等）
  3. 点击个人排名查看详细数据

#### 3.3.3 个人中心
- **功能说明**：管理个人信息、查看业绩数据
- **操作流程**：
  1. 进入"我的"页面
  2. 查看个人基本信息
  3. 点击"业绩统计"查看详细数据
  4. 点击"设置"进行账号管理

## 4. 角色权限说明

### 4.1 访客（Visitor）
- **权限**：只能查看公开内容
- **功能限制**：无法使用营销工具、无法查看课程详情
- **升级路径**：填写申请表，由管理员审核升级

### 4.2 学员（Student）
- **权限**：可学习课程，使用基础营销工具
- **功能限制**：无法使用高级CRM功能
- **升级路径**：完成培训课程，通过考核升级

### 4.3 主播（Anchor）
- **权限**：可使用所有营销工具，管理线索
- **功能限制**：无法查看其他主播数据
- **升级路径**：业绩达标，由管理员升级

### 4.4 经纪人（Broker）
- **权限**：根据业务类型（租赁、二手房、新房）分配不同工具
- **功能限制**：无法跨业务类型操作
- **操作指南**：
  - 租赁经纪人：重点使用合同管理、租后服务
  - 二手房经纪人：重点使用房贷计算、税费计算
  - 新房经纪人：重点使用楼盘分析、置业顾问

### 4.5 客户（Customer）
- **权限**：只能查看分享的内容
- **功能限制**：无后台操作权限
- **使用指南**：通过经纪人分享的链接进入，查看专属内容

### 4.6 租客（Tenant）
- **权限**：查看合同、申请服务
- **功能限制**：无法使用营销工具
- **使用指南**：通过合同编号登录，查看合同详情和服务

### 4.7 管理员（Admin）
- **权限**：全权限管理
- **功能限制**：无
- **操作指南**：详见《管理员操作指南》

## 5. 常见问题解答

### 5.1 账号问题

#### Q: 无法登录小程序怎么办？
A: 请检查网络连接，尝试重新授权登录。如问题持续，请联系管理员重置账号。

#### Q: 如何切换角色？
A: 在个人中心页面，点击"角色管理"，选择需要切换的角色。

#### Q: 账号被禁用了怎么办？
A: 联系管理员了解禁用原因，解决问题后申请重新启用。

### 5.2 功能问题

#### Q: 文案无法复制怎么办？
A: 请检查网络连接，尝试刷新页面。如问题持续，请联系技术支持。

#### Q: 客户数据丢失怎么办？
A: 小程序会自动备份数据，联系管理员进行数据恢复。

#### Q: 课程视频无法播放怎么办？
A: 检查网络连接，尝试切换网络环境。如问题持续，请联系技术支持。

### 5.3 技术问题

#### Q: 小程序卡顿怎么办？
A: 尝试清理微信缓存，关闭其他后台应用，或重新进入小程序。

#### Q: 图片无法加载怎么办？
A: 检查网络连接，尝试刷新页面。如问题持续，请联系技术支持。

#### Q: 分享功能无法使用怎么办？
A: 检查微信版本是否更新，尝试重新授权小程序权限。

### 5.4 其他问题

#### Q: 如何获取更多营销素材？
A: 定期关注小程序更新，或联系管理员获取最新素材。

#### Q: 如何提高获客效果？
A: 结合使用多种营销工具，保持内容更新频率，分析客户反馈调整策略。

#### Q: 如何查看业绩数据？
A: 在个人中心页面，点击"业绩统计"查看详细数据。
